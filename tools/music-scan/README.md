# Công cụ quét thư mục nhạc trên ổ đĩa để nhập vào CSDL music

Quét hết bài hát trong một thư mục, kể cả thư mục con của nó để đăng bài hát tự động. Một số điểm

- 

## Hướng dẫn

1. Cài đặt website nhạc trước, sau đó config lấy API key và mã bí mật
2. Chép config.sample.php thành config.php rồi cấu hình thông số cho đúng
3. Chạy `php scan.php` để quét và lưu bài hát
